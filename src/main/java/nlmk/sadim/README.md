
### Генерация классов пакета nlmk.sadim

Генерация классов пакета nlmk.sadim осуществляется по примеру сообщения из топика PA-MU.NLMK.P3.HSM.

Примеры сообщений можно найти по ссылкам:
- https://confluence.nlmk.com/pages/viewpage.action?pageId=75589394 (Спецификация передачи данных потока САДиМ - АСАП)
- https://confluence.nlmk.com/pages/viewpage.action?pageId=98221977 (Структура топика PA-MU.NLMK.P3.HSM)

Как вариант, это может быть сделано с помощью 
online-сервиса [http://www.jsonschema2pojo.org/](http://www.jsonschema2pojo.org/)
